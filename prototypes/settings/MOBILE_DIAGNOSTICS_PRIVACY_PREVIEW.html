FIREBASE CONSOLE

Όλα τα προβλήματα σε ένα dashboard

Μόνο οι λογαριασμοί που θα προσθέσεις εσύ στο Firebase project θα βλέπουν crashes, ANR, affected versions και stack traces. Οι χρήστες δεν αποκτούν πρόσβαση.

Χρειάζεται για την υλοποίηση

Δωρεάν Firebase project, καταχώριση του package com.prelude.iptv και το αρχείο google-services.json. Η αυτόματη συλλογή θα δηλωθεί false στο Manifest με firebase_crashlytics_collection_enabled=false.
