# Historical archive

These files document earlier implementation phases and validation runs. They are
preserved for traceability but are not authoritative descriptions of the current
application.

- `changelog/`: historical per-version and per-screen change notes.
- `build/`: one-off build stabilization and compiler-fix notes.
- `validation/`: generated validation, audit, compile and contract output.
- `history/`: superseded plans and miscellaneous historical notes.

For current information use the repository `README.md`, `CHANGELOG.md` and the
documents one directory above this archive.
