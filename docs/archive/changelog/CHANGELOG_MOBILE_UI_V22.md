# Mobile UI v2 Foundation — 1.22.0

- Added dedicated mobile-only primitives in `MobileV2Components.kt`.
- Mobile segmented controls now render as compact horizontally scrolling chips instead of TV-style full-width segments.
- Live TV mobile header now uses a dedicated touch-first composition.
- Live channel rows no longer apply TV focus modifiers on touchscreen devices.
- Mobile Live list uses flatter rows and subtle separators instead of a bordered TV panel.
- Mobile Live hero artwork now fills the feature card with a cinematic scrim.
- TV layouts and callbacks remain unchanged.
