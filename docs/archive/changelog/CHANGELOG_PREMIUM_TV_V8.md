# Premium TV v8 — Profiles & Parental Gate

- Added a dedicated Premium-style profile chooser before the catalog opens.
- Protected profiles require the existing parental PIN.
- The current profile opens immediately without restarting the app.
- Switching to a different profile recreates the activity with the correct profile-scoped favorites, recents, progress and locks.
- Added deterministic TV focus and neutral white focus treatment.
- Added a direct route from the profile chooser to profile management in Settings.
- Kept playlist/source credentials shared across profiles while retaining per-profile libraries and parental groups.
- Bumped app version to 1.8.0 (versionCode 8).
