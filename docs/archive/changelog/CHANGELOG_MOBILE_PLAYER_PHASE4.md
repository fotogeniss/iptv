# Mobile UI v2 — Phase 4

- Mobile live overlay keeps a single central play/pause action.
- Six quick actions are distributed evenly across the screen width.
- Channel browser is a full-screen dimmed bottom sheet on touch devices.
- Channel rows use larger touch targets, logos, channel number and current programme.
- Active channel uses a restrained red indicator only.
- Android TV player and channel side panel remain separate.
- Version 1.25.0 (28).
