# v11 Professional UI rewrite — foundation

This release starts the clean UI rebuild rather than continuing screen-by-screen styling patches.

- Expanded shared semantic design tokens and adaptive spacing.
- Added reusable primary/secondary media actions and progress component.
- Rebuilt the mobile Home hero from scratch using the approved HTML direction.
- Dedicated mobile hero sizing for compact and tall phones.
- Cleaner content hierarchy, scrims, typography and touch targets.
- Mobile catalog rails now use landscape cards for Continue Watching and portrait artwork for discovery rails.
- TV layouts remain separate and are not shrunk into phone layouts.
- Version 1.11.0 / code 12.
