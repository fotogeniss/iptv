# v19 Mobile Live implementation

- Routes Live TV through `PremiumLiveTvScreen` on both touch devices and Android TV.
- Removes the old generic channel-list composition from the mobile Live flow.
- Mobile now receives the approved adaptive layout: Now/Next feature card, EPG progress, compact filters, flat channel rows, and touch-first actions.
- TV keeps the existing two-column DPAD dashboard.
- Player remains View-based but uses the mobile-only single transport control, labeled quick actions, and full-screen channel sheet introduced in v18.2.
- Version 1.19.0 (22).
